# 30 Days DSA Interview Preparation

A structured 30-day journey to build **interview-level DSA problem-solving and pattern recognition using Java**.

This repository is the DSA track of my broader **30-day placement preparation sprint**, running alongside Java Backend, Spring Boot, and HireFlow-AI preparation.

---

## 🎯 Objective

The goal is not simply to accumulate solved problems.

The focus is to develop the ability to:

* Recognize common DSA patterns
* Approach problems independently
* Compare brute-force and optimal solutions
* Analyze time and space complexity
* Identify edge cases
* Explain solutions clearly in interviews
* Track mistakes and revisit weak areas

---

## 🧠 Daily Method

Each study session follows:

**20–30 min** → Concept learning
**60–90 min** → Problem solving
**20 min** → Review mistakes
**10 min** → Explain one solution aloud

For important problems, I record:

* Pattern
* Brute-force approach
* Optimal approach
* Time complexity
* Space complexity
* Key insight
* Mistakes / blockers

## 🔄 Problem-Solving Philosophy

I will follow this process instead of immediately looking at solutions:

**Understand → Think → Identify Pattern → Brute Force → Optimize → Code → Test → Review → Re-solve**

When stuck, the goal is to use a **small hint**, not immediately copy a complete solution.

Important failed problems will be revisited after a few days and again during the final review.

---

## 📈 Success Criteria

By the end of 30 days, the goal is to be able to:

1. Recognize common DSA patterns quickly.
2. Develop a reasonable solution independently.
3. Optimize a brute-force approach.
4. Clearly explain time and space complexity.
5. Solve common Easy/Medium interview problems in Java.
6. Identify and correct recurring mistakes.
7. Choose an appropriate data structure or algorithm for unfamiliar problems.
